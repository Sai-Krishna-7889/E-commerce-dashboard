# E-Commerce Sales Analytics Dashboard

An interactive E-Commerce Sales Analytics Dashboard developed using Python,
Pandas, Plotly and Streamlit.

## Features

- Total Revenue
- Total Orders
- Customer Count
- Average Order Value
- Monthly Revenue Analysis
- Product Performance
- Category Analysis
- Customer Lifetime Value
- Customer Purchase Patterns
- Seasonal Sales Trends
- Location-wise Sales Analysis

## Technologies

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## How to Run

Install the required packages:

    pip install -r requirements.txt

Run the dashboard:

    streamlit run app.py
